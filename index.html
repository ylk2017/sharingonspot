Keep captions short. Font sizes are explicit; the application does not silently shrink edited text. Longer text can trigger a layout warning.

The default presentation reports visible actions only. It does not claim enjoyment, confidence, improved attainment or class-wide engagement. Add a short, anonymised observation only if you can confirm its wording and source.

The response is included only when both fields and the confirmation are complete. It is labelled as presenter-supplied, not independently verified.
